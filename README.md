# DiscoverIt

Applicazione mobile Android che promuove il turismo nel territorio cesenate attraverso la gamification.

## Funzionalità

- Esplorazione di punti di interesse organizzati per categorie
- Check-in GPS per verificare le visite
- Sistema di achievement e progressi
- Funzionalità social per condividere con gli amici
- Personalizzazione profilo e tema chiaro/scuro

## Tecnologie

Jetpack Compose, Room Database, MVVM, Koin, Camera, Gallery, GPS, Location
